How to write a set

A set has a name, an optional description, a default check, an optional system message and [[questions]], each with a prompt and an answer. Checks:

  • number: the final answer is this number (tolerance sets how close; fractions like 5/36 work).
  • exact: the final answer is this text, ignoring case, spacing and end punctuation. accept lists other right answers.
  • choice: give choices; the answer is a letter. They're shown as A, B, C….
  • contains: the reply contains this text. regex: the whole reply matches this pattern. Add not = true to fail a match instead.
  • code: the model writes Python; its last code block is run, then your tests (Python, usually asserts). It passes if the tests finish without an error. No answer needed.
  • lean: a proof checked by the Lean prover. Give the statement (a Lean proposition) and any definitions in preamble; the model must write theorem goal : statement. answer may hold a reference proof, never shown to the model.
  • judge: for proofs and open answers. answer is a reference solution; a judge model you pick when running compares the reply with it and says pass or fail.

For number, exact and choice the model is asked to end with a line “Answer: …”. Thinking is not graded.

Each question is asked once, at temperature 1 with a fixed seed, one model at a time. Runs wait while a chat reply is being written, and pick up where they stopped. The estimate fits a straight line from your overall score to the Artificial Analysis Intelligence Index of the models that have one; it's an estimate, not a published score.
